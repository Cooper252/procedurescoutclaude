# Bundled pricing spec

Estimating the total episode of care. Phase 6.

## Principles

- Bundle templates are clinically reviewed.
- Each component records code, quantity assumption, setting, source price, payer/plan context, whether already included elsewhere, and confidence.
- Published package prices are never summed with their own components.
- Unknown components are shown as unknown, not filled in.
- Ranges only with stated assumptions; never labeled as statistical confidence intervals.
